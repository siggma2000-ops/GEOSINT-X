# GEOSINT X — Android v2.0.1

## Состав
- поиск: домен, IP, email, телефон (нормализация), публичный ник
- история последних запросов
- локальная SQLite-база
- копирование результатов и открытие внешних ссылок

## Получить APK через GitHub Actions
1. Создай пустой репозиторий GitHub с именем `GEOSINT-X`.
2. Загрузи в него всё содержимое этой папки, включая скрытую папку `.github`.
3. Открой вкладку **Actions** репозитория.
4. Выбери **Build GEOSINT X APK** и нажми **Run workflow** (или дождись сборки после push).
5. После успешной сборки открой запуск workflow и скачай артефакт **GEOSINT-X-APK**. Внутри будет APK.

Сборка рассчитана на Android ARM64. Для установки скачай APK на телефон и открой его; Android может попросить разрешить установку из выбранного источника.

## Локальная сборка на Linux/WSL2
```bash
python3 -m pip install --user buildozer cython
buildozer android debug
```
APK появится в `bin/`.

## Примечания
- База хранится локально в данных приложения.
- Проверка формата email/телефона не подтверждает существование ящика или владельца номера.
- Приложение не определяет владельцев частных номеров или точную геолокацию людей.
- Сборка APK в этой среде не запускалась: Android SDK/Buildozer здесь отсутствуют.
